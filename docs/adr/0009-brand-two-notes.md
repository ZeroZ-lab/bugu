# 0009 品牌图形用"一实一空"的两声,品牌色只用墨色

日期:2026-11-12

## 背景

M2 的应用图标是绿底白色同心圆,只是临时占位。它看起来像录音键或相机,和"布谷"没有联系。主色墨绿和"成功"状态的绿色混在一起。菜单栏还缺一个能显示状态的单色图标(G9)。

## 决定

1. **图形**:布谷鸟一次叫两声。图形是两个圆,左上大圆为实心,右下小圆为空心:第一声已经响过,第二声还没到。几何定义见 [resources/logo.svg](../../resources/logo.svg)。
2. **一条规则贯穿界面**:空心表示还没发生或正在发生,实心表示已经有了结果。菜单栏图标、运行状态标记、收件箱的未读标记都按这条规则画。
3. **菜单栏图标就是状态灯**:平时就是 logo;运行中,空的那一声变成转动的虚线圈;有新结果,空的那一声被填满,旁边显示条数;有失败,填满的那一声为红色。
4. **品牌色只用墨色**:深色模式下反转为接近白色。彩色只用来表示状态。
5. **字标**:英文和命令行一样写成小写 `bugu`,用等宽字体。中文场合写"布谷",用系统字体。

具体的颜色、尺寸、组件写法见 [DESIGN.md](../DESIGN.md)。

## 理由

- 两声比钟、鸟、表盘都简单,16px 的菜单栏里仍然清楚。
- 空着的第二声表示"等待",被填满表示"有事"。这正是 PRD 第 2 章"没有新内容就不打扰":菜单栏图标不变,就说明没有事要看。
- 品牌色和状态色分开以后,绿色只表示成功、红色只表示失败,不会因为主色是绿色而读错。
- 图形是纯单色,可以作为 macOS 的模板图标,系统自动适配深色和浅色菜单栏。只有"有失败"一种状态需要彩色图片。
- 用空心和实心区分状态,色觉障碍的用户不靠颜色也能分辨"发生了没有"。
- 等宽的 `bugu` 和命令行里输入的名字一致。

## 否决的方案

- 现在的同心圆:和产品没有联系。
- 布谷钟的小门、鸟头加表盘:意思更直白,但在 16px 下线条会糊。
- 两个实心圆:少了"等待"和"有结果"的区别,菜单栏图标没法兼做状态灯。
- 墨绿、石板蓝灰、赭橙作为品牌色:要么和状态色冲突,要么只能在图标上用、到界面里没有作用。

## 后果

- 应用图标、菜单栏图标和前端的颜色变量要按新规范重做。
- "有失败"状态的菜单栏图标是彩色的,深色和浅色菜单栏要各准备一张。
- 墨色作为品牌色,在 Dock 和图标列表里不如彩色醒目。
