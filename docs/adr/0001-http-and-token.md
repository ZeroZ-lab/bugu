# 0001 统一使用 HTTP 加令牌

日期:2026-11-11

## 决定

后台只暴露一套 HTTP JSON 接口。本机命令行、桌面窗口、浏览器、远程管理全部走它。所有请求必须携带令牌,没有免认证模式。默认只监听本机地址。

## 理由

- 用户希望在客户端"填一个地址就能连上服务器"。
- 一种连接方式意味着一条代码路径,本机和远程的行为不会出现差异。
- 接口能创建任务,等同于能执行任意命令,所以认证不能是可选项。

## 否决的方案

- Unix 套接字用于本机、另一种方式用于远程:两条路径,且浏览器无法使用套接字。
- 内置 SSH 通道:不用自己做认证,但用户要为每台服务器配置 SSH,网页面板也无法复用。用户仍可自行用 SSH 端口转发,不需要我们写代码。

## 后果

令牌管理、默认监听本机、请求来源校验从第一版起就是必须项(PRD 7.10)。公网访问的加密交给反向代理或组网工具。
